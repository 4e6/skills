# research-plan-build-review

An [Agent Skill](https://agentskills.io) that carries a task through research,
plan, build and review, and delivers whatever the task asked for: findings, a
plan, a change, or work run. Ask your assistant to investigate, decide, fix,
build or audit something; no issue or ticket is needed.

It works best where the assistant can start subagents, which do the reading and
the reviewing in a context of their own. Without them, each role is a separate
pass by the same assistant.
