# work-on-github-issue

An [Agent Skill](https://agentskills.io) that takes a GitHub issue and produces
a reviewed pull request, merged, in any GitHub repository. Give your assistant
an issue — `#123`, `owner/repo#123` or a link. Say "don't merge" to keep the
merge yours.

## Requirements

`git`, and the [GitHub CLI](https://cli.github.com) (`gh`) signed in with
access to the repository.
