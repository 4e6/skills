# Convention

* [A change and its wiki are one commit](a-change-and-its-wiki-are-one-commit.md) - A PR changes the code and every page it touches in one squashed commit, pinned to the commit it branched from. Nothing is pinned after a merge.
* [Editing a skill](editing-a-skill.md) - Re-read the upstream guides before editing and never copy them here. The skill states the rule and this bundle carries the argument. Prose is not cut on argument alone; a change to behaviour or to the page is judged by running it.
